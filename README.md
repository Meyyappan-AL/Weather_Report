# 🌤️ Weather Report Dashboard

A full-featured, interactive, and responsive web application designed to deliver real-time weather analytics, multi-day forecasts, and climate data for locations around the globe. Built with modern web technologies, this dashboard features an intuitive UI complete with dynamic light and dark mode toggling.

🚀 **Live Deployment:** [Live Demo](https://meyyappan-al.github.io/Weather_Report/)

---

## 📸 Key Highlights

* 🌍 **Global Coverage:** Fetch real-time weather conditions for any city worldwide.
* 🌗 **Dynamic Theme Switching:** Native Light and Dark mode toggles for optimal viewing day or night.
* 📊 **Comprehensive Metrics:** Displays detailed metrics including ambient temperature, humidity levels, atmospheric pressure, visibility, and wind speeds.
* 📱 **Fully Responsive UI:** Seamlessly adapts across desktops, tablets, and mobile devices.

---

## 🛠️ Tech Stack & Dependencies

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Styling:** Custom CSS Flexbox/Grid Layouts, Media Queries
* **Version Control:** Git & GitHub
* **Hosting:** GitHub Pages
